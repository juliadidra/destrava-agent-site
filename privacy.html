Política de Privacidade

Última atualização: 21 de outubro de 2026.

Destrava Agent é um aplicativo de uso pessoal, operado por seu próprio dono em um servidor que ele controla. Esta política descreve quais dados do Google o aplicativo acessa e como eles são tratados.

Dados acessados

Com a autorização do dono da conta, o aplicativo usa o escopo https://www.googleapis.com/auth/calendar.freebusy para consultar apenas a disponibilidade da Google Agenda (quais horários estão livres ou ocupados), com o objetivo de calcular o tempo livre de cada dia. O aplicativo não tem acesso a títulos, descrições, locais ou participantes dos eventos.

Como os dados são usados

  • Os dados da agenda são usados apenas para planejar as tarefas do próprio dono da conta.
  • O aplicativo não lê o conteúdo dos eventos e não altera, cria nem apaga eventos.
  • Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade.
  • Nenhuma pessoa lê os dados da agenda, exceto o próprio dono.

Armazenamento

A credencial de acesso (refresh token) fica guardada somente no servidor do dono, em variáveis de ambiente, fora de qualquer repositório público. As informações de disponibilidade são consultadas sob demanda e não é copiado para serviços externos.

Uso de dados de APIs do Google

O uso e a transferência de informações recebidas das APIs do Google por este aplicativo seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogação do acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Após a revogação, o aplicativo deixa de ter acesso à agenda.
